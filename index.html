What a 30-day design-partner pilot looks like

Success metric: did Parable reveal material information the underwriter otherwise wouldn't have had?
Week 1 · Workflow discovery
Map submission → enrichment → analysis → quote/decline → referral → bind. Find where missing evidence changes a decision.
Weeks 2–3 · Instrument one workflow
Connect only the telemetry required for a useful signal — no "boil the ocean" integrations.
Week 4 · Shadow underwriting
Run alongside existing underwriting. Parable doesn't decide; it surfaces additional evidence.
